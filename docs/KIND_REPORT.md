# KIND 인덱스 리포트(HTML) 사양

코드 `kind/html_report.py`(데이터 구성) + `kind/html_report_template.html`(화면). 출력 `kind/reports/kind_report_<기준일>.html`(단일 파일, 외부 의존 없음, 라이트/다크, 모바일 1열).
`.venv/bin/python kind/html_report.py [YYYY-MM-DD]` — 날짜를 주면 그 날 이전 마지막 영업일이 기준일(10/09 휴장 → 10/08). 양식은 DART 리포트(`report_v2/AGENT_SPEC_V3_basic.md`)를 따른다: 네이비 헤더 밴드 · KPI · 핵심 포인트(칩) · 뉴스 근거 · 원문 링크 1개.

## 1. 원칙 (사용자 지침)
- 사람의 주의력은 한정된 자원 — **지수 주식수에 직접 닿는 것만** 화면에 둔다. 우선주·우리사주·일반공모·정정 이력·시장조치·종목별 원장은 DB 에만.
- **중요 요소**(지수 주식수 변동·시총 변동·지수 반영일)는 ★ 로 표지(노란 KPI 카드, '★ 중요' 칩, 일정표 ★ 행).
- 근거는 KIND 원문 링크 **하나**(대표 결정 공시, 가장 최근 정정 포함).
- 추정치 설명은 화면에 쓰지 않는다 — '추정' 표기만, 필요하면 `(?)` 툴팁.
- 상장주식수 기준(유동비율 미적용). 시총 변동 = 변동 주식수 × 기준일 종가(추정).

## 2. 4탭
| 탭 | 들어가는 것 | 정렬 |
|---|---|---|
| **일정 확정** | 유상증자·무상증자·주식배당·액면분할·합병·분할(결정 공시의 상장 일정이 있는 건), 소각은 *변경상장 공시가 올라온 건만* | **앵커 날짜가 가장 오래된 것이 위.** 앵커 = 권리락일(주주배정 유상증자·무상증자, 주식배당은 배당락일)이 있으면 그것, 없으면 신주 상장일 / 변경상장일. 제3자배정·공모·합병은 상장일 앵커 |
| **일정 미확정** | 변경상장 공시 전의 자기주식 소각(소각 대기·취득 중·취득 종료 후), 하단에 CB/BW 장기 대기 | **변경상장 예정일(임시 추정)이 빠른 것이 위.** 추정이 없으면 맨 아래 |
| **자기주식 취득 진행** | 기준일 현재 취득 중인 자기주식 취득(`자기주식 취득 결정`·`자기주식취득 신탁계약 체결 결정`) — 소각 목적 여부 무관. 금액 한도를 채운 프로그램은 '소진 완료'로 맨 아래 | 기본 *남은 취득액 내림차순*. 필터 [전체/소각 목적/그 외], 정렬 [남은 취득액 순/규모 순/종료 임박 순(예상 소진일 기준)]. 막대: 누적 체결(회색)·남은(주황), 길이는 규모 비례. 행마다 취득률·누적 체결금액·최근 10거래일 일평균·예상 소진일(계획 종료보다 빠르면 표기)·'소각 목적/소각 아님' |
| **최근 종결** | 신주·변경상장 후 2~7일 | 최근순. 7일이 지나면 리포트에서 사라진다 |
- 신주 상장 후 **2일 이상** 지나면 '일정 확정'에서 '최근 종결'로 이동(2일 미만은 확정 탭에 남음).
- 목록 행: 종목명·코드 · [관리종목] · 유형 태그 · [⚠ 리스크/이슈] · 시총 변동 · 변동 주식수(%) · 일정 한 줄 · 상대 크기 막대. 행 선택 시 우측(모바일은 아래) 상세.

## 3. 상세 패널 구성
헤더 밴드(종목·유형·한 줄 헤드라인) → KPI 4(★ 지수 주식수 변동 / ★ 시총 변동 / ★ 지수 반영일 / 유형별 1개: 발행가·취득기간·합병비율 등) → 핵심 포인트(칩: 메모·★ 중요·왜·리스크·참고) → 일정 표(핵심 일정만, 지난 일정은 '완료', ★ 행 = 지수 반영일) → 뉴스 근거(≤3, 매체·날짜·제목 링크) → 푸터 KIND 링크.
- **유형 태그**: 유상증자(주주배정) / 3자배정 유상증자 / 공모 유상증자 / 자기주식 소각 / 합병 / 인적분할 / 무상증자 / 주식배당 / 액면분할 / CB·BW n회.
- **⚠ 태그**: `kind/news.json` 항목의 `tag`(현재 SK이노베이션 합병 '리스크', 금양 '상폐 이슈').
- **관리종목**: `status_flag` 테이블(`kind/status_flags.py`, KIND 시장조치 0350 지정/지정사유변경/지정해제 최신 상태, 우선주 지정 제외). 빨간 표지.

## 4. 데이터 소스와 산식
| 값 | 출처·산식 |
|---|---|
| 변동 주식수 | 스레드 `detail_json`: 유상증자 신주수(실제 상장 시 원장 값) · 소각 소각수량(보통주만) · 합병 신주 · 분할 존속 감소 |
| 시총 변동 | 변동 주식수 × `kind/universe/prices_<기준일 이하 최신>.csv` 종가 — 가격이 없으면 '-' |
| 상장주식수 대비 % | 원장 상장주식수(없으면 결정 공시의 증자 전/소각 전 발행주식수) |
| 지수 반영일 | 주주배정·무상·주식배당: 권리락/배당락일 / 제3자·공모·합병: 신주 상장일 / 소각·액면분할·분할: 변경상장일 |
| 소각 변경상장 예정일(추정) | 소각일이 있으면 소각일 + 중앙값 약 11영업일. 없으면 (취득 종료일, 체결내역 기준 *예상 소진일*이 더 빠르면 그 날) + 과거 간격 중앙값(그 법인의 과거 프로그램 3건 이상이면 법인별, 아니면 전체 약 36일). 변경상장 공시가 나오면 확정 |
| 자기주식 취득 진행률 | **실적**: KIND `자기주식매매 체결내역(유가증권시장)`(시장조치 0326, 하루 1건·전 종목)의 체결금액을 계획 시작일부터 합산(직접·신탁) ÷ 취득 예정금액. 남은 취득액 = 예정금액 − 누적. 예상 소진일 = 최근 10거래일 일평균 체결금액으로 남은 금액을 채우는 날(계획 종료일로 캡). 한도는 금액이다(신고수량 초과 매입 가능 — 삼성전자 누적 5,686만주 = 신고 5,329만주의 106.7%인데 금액 15조원 소진 시점에 종료). 체결내역이 없는 종목만 기간 경과 비례 추정(`basis=time`). 마지막 체결이 오래돼 예상 소진일이 과거면 '최근 체결 없음' |
| CB/BW | 잔여 전환 가능 주식수(`m2_cbbw`) × 종가 = 잠재 시총, 상위 6건만 |

## 5. 목록에서 빼는 것
- 시총 변동 **50억원 미만**(`MIN_MC`) — 개수만 헤더에 표기.
- 우선주만의 소각, 보통주 신주가 없는 증자, 신주 없는 합병(100% 자회사 흡수 등), 상장 공시가 없을 소각(비상장 종류주식·합산 공시 추정 `unmatched_stale`).
- **제외 종목** `kind/universe/exclude.txt`(단축코드 + 사유) — 현재 태영건설(009410). 리포트·스캔·등록에서 제외, DB 에 이미 있는 공시는 지우지 않는다.
- CB/BW 하위(`CBW_TOP`=6 초과분).
- **시총·거래대금 맥락(삼성전자·SK하이닉스만, 사용자 지침)**: `kind/universe/bb_quotes.json`(MCP `trading_data(scope=quote, company, as_of)` 일별 시세 — 종가·거래량·거래대금·시총, 최근 10거래일)이 있는 종목은 취득 행에 '시총 대비 계획·남은 %', '최근 10거래일 일평균 거래대금 대비 매입 비중(금액·수량)', '남은 금액 = 일 거래대금 며칠치'가 붙는다(2026-10-08: SK하이닉스 계획 시총의 3.26%·남은 0.40%·매입 비중 18.6%·남은 금액 1.0일치, 삼성전자 계획 0.98%·매입 비중 9.0%·소진). 갱신: 기준일 이하 최근 10거래일을 종목별로 조회해 `days` 에 추가(주 1회 종가 갱신 때 함께). 다른 종목에는 붙이지 않는다.
- 취득 진행 탭 맥락: `news.json` 의 `BB:<단축코드>` 항목(`note`+`news`)이 행 하단에 표시된다(삼성전자·SK하이닉스: 소각 여부에 따른 지수 영향 + 수급 기사).

## 6. 입력 파일
- `kind/news.json` — 스레드 키별 `why`(왜 한 줄)·`risk`·`memo`·`tag`·`news[]`. 키: 유상증자 `PCI:<issuer_id>:<최초제출일>:<R|T|P>` · 소각 `CXL:<issuer_id>:A<취득시작일>` 또는 `CXL:<issuer_id>:<최초결정일>` · 합병 `MRG:<issuer_id>:<최초제출일>` · 분할 `SPL:<issuer_id>:<일자>`. 뉴스는 기준일 이하 게재분만, 날짜·매체는 기사 페이지에서 확인한 것. 현재 등록: 삼바(R)·SK하이닉스·SK이노베이션·금양(T)·대한항공·카카오(memo).
- `kind/universe/prices_<YYYYMMDD>.csv` — 주 1회 종가(`save_prices.py`, git 추적). `kind/universe/exclude.txt` — 제외. `kind/universe/kospi_list_clean.md` — DART 모듈 명단 사본.

## 7. 화면 확인 방법
```
.venv/bin/python kind/html_report.py 2026-10-09
node <scratchpad>/shot3.js <출력접두>      # playwright(레포 node_modules)로 4탭 스크린샷
```
콘솔 오류 없음 확인(`pageerror`). 마크다운 리포트(`daily_report.py`·`m2_report.py`)는 폐지됐다 — 필요하면 `git show 33f027e:kind/daily_report.py`·`33f027e:kind/m2_report.py` 로 이전 렌더러를 볼 수 있다(원장 현황·변동 이력·시장경보 절은 HTML 에 없고 DB 에만 있다). 회귀 비교는 `kind/regress.py`(HANDOFF 3절).
