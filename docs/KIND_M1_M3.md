## 2. M1 — 시장조치 → 주식수 원장 / 기준가 / 정지

### 2.1 처리하는 서식
| 제목 | 읽는 항목 | 산출 |
|---|---|---|
| `변경상장(사유)` | 종류별 `변경전 → 변경후`, 변경주식수, **변경상장일**, 발행일(소각일), 표준코드 | `share_ledger` (before/delta/after, effective=변경상장일, issue_date) |
| `추가상장(사유)` | 종류·수, 발행일, 상장일, 코드 | `share_ledger` (잔고는 직전 잔고+증감으로 **계산**, `is_computed=1`) |
| `…기준가격 안내` | 회사, 주권종류별 기준가격(분할은 평가·최고·최저), 사유, **적용일** | `event` (RIGHTS_EX / DIVIDEND_EX / SPLIT_RELIST_PRICE…) + `EX_DATE` |
| `매매거래정지(및정지해제)` | 정지일, 해제일(또는 **조건**), 사유 | `event` HALT + `HALT_START`/`HALT_END` |

### 2.2 규칙
- 원장의 기준일은 **변경상장일** (발행·소각일과 다름: 삼전 소각 4/2 → 상장 4/14).
- 조건부 해제일(예: `변경상장일`)은 `condition_note` 로 남기고, 이후 변경상장 공시의 "매매거래정지가 해제됨" 문구로 확정 — 이전 값은 `superseded_by`로 이력 보존.
- 우선주는 제목 `(…우)` 또는 종류 `1우선주`로 구분, ISIN은 상장 공시의 표준코드에서 자동 보충.
- 선물·옵션/종속회사 공시는 수집 단계에서 skip.

## 3. M3 — 시장경보·공매도·거래정지 기간 추적

### 3.1 상태 머신 (종목별)
```
[투자주의 1일]  특정계좌 매매관여 과다 등             → CAUTION        (시작=종료=지정일)
[투자경고 지정예고]  예고일 1일 투자주의 + 판단기간    → WARNING_NOTICE (예고일 ~ 판단 마지막일(순연 한도))
        ├─ 판단기간 내 요건 충족 → [투자경고 지정]      → WARNING        (지정일 ~ 최초 해제판단일(가능 최단, 추정))
        │                              └─ [지정해제] → 종료 확정 (해제일 직전 영업일)
        └─ 미충족 → 예고만 하고 종료
(투자위험 ← 경고 이후 추가 급등: 서식 미관측, 미구현)
[공매도 과열 지정]  지정일 1일간(−5% 하락 시 연장)    → SHORT_BAN
[매매거래정지]  M1의 HALT 이벤트에서 파생              → HALT           (정지일 ~ 재개일 직전 영업일, 조건부면 미정)
```
- **종료일 규약**: `end_date` = 지정된 *마지막 날(포함)*. 공시의 "해제일"은 첫 비지정일이라 직전 영업일로 환산.
- 추정 종료일(`end_is_estimated=1`)은 해제 공시 전까지의 *가능 최단*이며, 해제요건 불충족 시 하루씩 순연된다. 해제 공시가 오면 확정으로 갱신.
- 상태는 기준일(as-of)로 재계산: 확정 종료일이 기준일 이전이면 ended, 경고·정지는 해제 공시 전까지 active.

## 5. 알려진 한계
1. 3종목 1년 데이터라 관측 서식이 적음 — **투자위험, 단기과열, 공매도 연장·해제, 거래정지 단독 해제, 액면분할·병합 기준가 등은 서식 미관측**(코드는 review로 빠지도록 되어 있음). 300종목 확장 시 신규 서식이 review 큐로 나옴.
2. 투자경고 추정 종료일은 "최초 해제판단일"이며 실제 해제는 순연·조기 해제가 있을 수 있음(SK하이닉스 사례).
3. 지정예고 판단 기간에 한계: 공시상의 "순연 한도"를 그대로 쓰며 종목 거래정지 시 변경은 반영하지 않음.
4. 시장 전체 공시(대량매매 등)·ETF의 지수 변경 안내는 아직 이벤트화하지 않음.
