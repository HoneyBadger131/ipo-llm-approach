2. 판정 결과 다섯 가지Jev가 공시마다 하나를 붙입니다

결과의미리포트에서의 모습
통과중요한 공시입니다. 상세 분석으로 보냅니다.상세 리포트가 생성됩니다.
통과·확인중요한 공시이며, 규모나 비교 기준을 계산해서 확인해야 합니다.상세 리포트에 확인한 수치가 들어갑니다.
알림알아두면 좋지만 깊이 분석할 필요는 없는 공시입니다. 예: 대표이사 변경브리프 맨 위에 한 줄로 표시됩니다.
보류판정이 애매합니다. 일단 분석으로 보내고 사람이 다시 볼 수 있게 표시합니다.상세 리포트가 생성됩니다.
제외일상적이거나 정례적인 공시입니다. 예: 소액 거래, 형식 정정, 풍문 해명리포트에 나오지 않습니다.

제외 기준은 운용역의 판단을 반영하여 정했습니다. 예를 들어 금융회사의 일상 거래, 단순 연장·대환, 기간이나 상대방 이름만 바뀐 정정 공시는 제외합니다.

3. 리포트 읽는 방법PDF 한 권, 또는 HTML 한 파일

통합 PDF

  • 맨 앞 1~2쪽이 브리프입니다. 중요도 높은 공시 10건이 카드로 나오고 나머지는 표로 나옵니다.
  • 카드나 표의 행을 누르면 해당 종목의 상세 페이지로 이동합니다. "상세 p.7"처럼 쪽 번호도 적혀 있습니다.
  • 상세 페이지 오른쪽 아래의 "↑ 브리프" 버튼을 누르면 첫 쪽으로 돌아옵니다.
  • 상세 페이지는 중요도 순서대로 이어지고, 북마크 창에서도 이동할 수 있습니다.

HTML 파일

  • 파일 하나로 되어 있어 인터넷 연결이 없어도 열립니다.
  • 요약 화면에서 공시를 누르면 종목별 상세 화면이 열립니다.
  • "↑ TOP" 버튼으로 요약 화면에 돌아오고, "이전·다음" 버튼으로 옆 종목으로 이동합니다.
  • 뉴스 링크는 링크로 남아 있어, 인터넷이 연결된 환경에서 누르면 열립니다.

중요도 ●○ 다섯 단계

같은 날 올라온 공시끼리 비교하는 척도입니다.

  • 5 매출·자기자본의 10% 이상이거나 사업 구조의 근본적 변화
  • 4 5~10%이거나 신사업·대형 계약·대규모 주주환원
  • 3 1~5%의 의미 있는 결정
  • 2 1% 미만이지만 알아둘 이슈 · 1 참고

건설·조선사의 국내 수주는 일상적인 영업이므로 한두 단계 낮춰 평가합니다(국내 재건축·재개발은 두 단계). 해외 수주는 낮추지 않습니다.

투자심리(투심) 표시

  • ▲ 긍정적 · ▼ 부정적 · ◆ 혼재됨 · ? 알 수 없음
  • 색뿐 아니라 기호와 글자로도 구분하여 인쇄물에서도 읽을 수 있습니다.

출처 표기

  • 수치는 공시 본문에서 가져오고, 직접 계산한 값은 계산했다고 표시합니다.
  • 뉴스는 기준일 이전에 게재된 기사만 사용합니다.

4. 현재 수준과 한계

판정 정확도

9월 한 달의 공시를 사람이 정한 정답과 비교한 결과입니다.

  • 분석이 필요한 공시 100건 중 약 95~96건을 통과시켰습니다.
  • 통과시킨 공시 중 실제로 필요한 공시는 약 83%입니다. 나머지는 확인해 보니 중요하지 않은 공시입니다.
  • 놓치는 쪽보다 불필요하게 통과시키는 쪽으로 기울어 있습니다.

알아두실 점

  • 정보 제공용 자료이며 투자 권유가 아닙니다.
  • 자동 판정이므로 일부 공시는 놓치거나 불필요하게 포함될 수 있습니다. 판정 기준은 운용역의 의견을 받아 계속 고치고 있습니다.
  • 거래소(KIND) 공시와 주식수 변동 리포트는 아직 포함되어 있지 않습니다.
