## 1. 자기주식 소각 (8개 스레드: 삼성전자 2, SK하이닉스 2, 한화솔루션 1, 한화(주) 3)

**흐름** `주식 소각 결정(+정정)` → [취득 후 소각형이면 `자기주식 취득` 기간] → **소각일** → `변경상장(주식소각)` 공시 → **변경상장일 = 지수 주식수 감소일**. 소각일은 지수와 무관.

| 유형 | 사례 | 특징 |
|---|---|---|
| 기취득 자기주식 소각 | 삼성전자(보통 73,359,314 + 우선 13,603,461, 소각 4/2 → 변경상장 **4/14**), SK하이닉스 1,530만주(2/9 → **2/23**), 한화솔루션우 30,733주(8/4 → **8/18**) | 결정 공시에 소각예정일 명시 |
| **취득 후 소각**(진행 중) | **SK하이닉스 2026-08-19**: 취득 8/20~11/19(장내매수, SK증권), 예정 24,070,000주 / 40.0조원(8/18 종가 1,662,000원 기준 산정), 소각예정일 `-`(취득 완료 후 일괄) | 수량·금액은 취득 결과로 변동 → 정정공시 예정. 변경상장일 미정 |

**관측 규칙(4건)**: `변경상장 공시일 + 3영업일 = 변경상장일` (4/4 일치), `소각일 → 변경상장일 7~9영업일`(중앙 8.5). 소각일이 정해지면 변경상장일을 *추정 범위*로 표기, 공시가 나오면 확정.
**SK하이닉스 진행 건 예상**: 취득이 종료 예정일(11/19)에 끝나 같은 날 소각하는 가정에서 변경상장일 약 **11/30 ~ 12/2**, 상장주식수 730,492,365 → 약 706,422,365(−3.30%, 수량은 예정치). 취득이 일찍 끝나면 앞당겨짐. *자기주식 취득 진행 현황(결과보고서)은 수집 범위 밖 — 완료 후 확인.*

## 2. CB / BW — 전환·행사 상장 이력 + 잔여 희석분 (3개 시리즈)

**지수**: 전환·행사로 늘어난 주식은 **전환(행사) 신주 상장일**에 증가 (붙임2 9-가). 개별 상장은 M1 원장이 이미 기록, M2는 *회차(시리즈) 단위로 묶어* `발행 당시 가능 주식수 − 누적 전환 = 잔여 가능 주식수(희석 overhang)`를 추적.

| 시리즈 | 조건 | 현황 (2026-10-10) |
|---|---|---|
| **하이브 CB 제4회** (사모, 4,000억, 0%) | 전환가 218,000원, 최대 1,834,862주(4.41%), 청구 2025-10-17~2029-09-17, 풋 2027-10-17~ | 누적 **1,454,739주(79.3%)** 상장 16건, 잔여 **380,123주**(≈829억, 상장주식수의 0.88%) |
| **엘앤에프 BW 제7회** (공모·분리형, 3,000억) | 행사가 50,002원, 최대 5,964,185주(14.18%), 행사 2025-10-09~2030-08-09, 리픽싱 최저 35,002원, 풋 2027-09-09 | 누적 **4,320,867주(72.4%)** 상장 15건, 잔여 **1,643,318주**(≈822억, 4.04%) — 신주인수권증권 *엘앤에프 7WR*(2025-09-22 상장) |
| 엘앤에프 CB 제6회 (사모, 1,000억) | 전환가 103,974원, 최대 961,778주(2.65%), 청구 2026-01-10~ | 전환 0건, 잔여 961,778주 |

**검증(독립 근거와 일치)**
- 하이브: DART/KIND `전환청구권 행사` 공시(2026-01-28)의 잔여 전환가능 **447,474주** = 우리 계산 447,474주(그 시점까지 *청구된* 수량 기준). 이후 청구분 67,351주를 빼면 현재 잔여 380,123주.
- 엘앤에프 BW: 최신 신주인수권증권 변경상장 공시의 *잔여 1,643,318증권* = 우리 계산 `5,964,185 − 4,320,867` ✅.
- 엘앤에프 원장: DART `자본금 변동사항`의 **2025년말 40,238,914주**·**2026-06-30 40,683,260주** 와 원장 체인이 정확히 일치.
**발견**
1. **DART 발행주식총수는 *발행일* 기준, 우리 원장·지수는 *상장일* 기준.** BW·CB는 청구 후 약 2주 뒤 상장되므로 시드(6/30)가 "발행됐지만 아직 미상장" 주식(엘앤에프 115,317주: 7/9·7/20 상장분)을 이미 포함. → 시드를 `DART 발행총수 − 발행됐지만 시드일 이후 상장`으로 보정(`seed_adjust`, 발행일별 수량 `issue_detail` 보존). 지수 관점에서는 이 보정이 맞음.
2. **같은 회차를 이사회가 여러 번 재결의**(엘앤에프 BW 7회: 6/16, 6/27, 7/8, 7/15 + 8/28 정정) — 정정이 아니라 *신규 결정서*로 올라옴. (법인, 종류, 회차)가 같고 앞 결정의 납입일 이전이면 한 시리즈로 병합.
3. 발행일 서식이 둘: `- 날짜 : N주` / `날짜(N주)` — 둘 다 파싱, 발행일별 수량 보존.
4. 상세검색은 종목 지정이어도 **1년 초과 구간이면 오류 없이 0건**(CB 행사공시 조회에서 재발견) → 모든 조회를 330일 구간으로 분할.
5. 한화(주)는 *제1우선주(한화우, 000885, 상장폐지 2025-07-15)* 와 *3우선주(한화3우B, 00088K)* 가 있어 한 공시에서 우선주 종류별로 구분 필요 → 종류 라벨별 코드 매핑으로 보완.
