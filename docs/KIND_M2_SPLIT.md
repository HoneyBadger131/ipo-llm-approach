# KIND M2 — 회사분할(인적분할) 스레드

작성 2026-10-10 · 코드 [`kind/m2_split.py`](../kind/m2_split.py) · 카드 `m2_report.split_card` · 규칙 근거 [`KIND_INDEX_METHOD.md`](KIND_INDEX_METHOD.md) 4절

## 1. 규칙(사용자 확정, 구현 반영)
- **존속법인**: 지수 주식수 감소일 = **변경상장일**. 감소 수량 = 변경상장 공시의 `변경전 → 변경후`(종류별).
- **신설법인**: **별개 종목**(재상장일 = 존속 변경상장일과 같은 날). 인적분할의 신설법인은 **워치리스트(`phase1`)에 자동 추가**(`m2_split.py --register`가 결정 공시의 신설법인명을 KIND에서 해석).
- **신설법인 상장주식수**: 재상장 공시 전에는 **계산값** = 존속 감소분 × (분할회사 1주의 금액 ÷ 신설회사 1주의 금액). **재상장 공시 수치가 있으면 그 값으로 덮어쓴다**(원장에는 공시값만 남고, 카드에 계산값과의 차이를 표기).
- **물적분할**은 범위 밖: 스레드만 만들고(`CORPORATE_SPLIT_PHYSICAL`) 주식수 조정 없음. 자회사 공시(제목 `(자회사의 주요경영사항)`)는 수집 단계에서 걸러진다.
- 현금 처리(분할 후 첫 매매일 익일 기준시총 수정)는 우리 범위 아님(주식수만 추적). 2026-11 개정 후 규칙은 근거 문서 수령 후.

## 2. 스레드 흐름과 읽는 항목
`회사분할 결정(+정정)` → `임시주주총회 결과` → `매매거래정지(회사분할에 따른 전자등록 변경, 말소)` → `변경상장(회사분할(존속))` → `변경상장 기준가격결정방법 안내` ; 신설법인 쪽 `재상장(…, 상장일 …)`(+ `재상장 기준가격결정방법 안내`).
- 결정 공시(16항목)에서 읽는 것: 분할방법(인적/물적) #1 · **분할비율 #4** · 신설회사명·재상장 여부 #7 · **감자비율·거래정지 예정기간·배정비율·배정기준일·신주 상장예정일 #8** · 이사회·주총·분할기일·등기일 #9. 나머지는 읽지 않는다.
- 정정은 *정정 표 + 정정 반영 전문* 구조라 마지막 `회사분할 결정 / 1. 분할방법` 이후만 읽으면 최신값. 정정 diff(일정·비율)는 카드 접힘 영역에 표시.
- 스레드 키 `SPL:<issuer_id>:<최초 결정일>`(정정의 `최초제출일`로 묶음). 매번 처음부터 replay(멱등).
- 공시 전(예측) 경로: 결정 공시의 `신주의 상장예정일`을 추정 변경상장일로, `감자비율(분할비율)×상장주식수`를 예정 감소분으로 `index_share_adj`(PLANNED)에 넣는다. 변경상장 공시가 원장에 들어오면 선반영이 자동으로 사라진다(테스트: 한화 예정 −17,179,021 vs 실제 −17,179,022, 1주 차이).

- 한화 보통주 계산 차이 = **분할 시점 자기주식에는 신설 주식을 배정하지 않음**(결정 공시 #8 배정조건). 존속의 감소분은 자기주식 몫도 포함(감자비율×전체 상장주식수)이라 신설 계산값이 과대. 우선주는 자기주식이 없어 일치. → 계산값은 *상한 근사*, 재상장 공시(변경상장 공시 +1영업일 전후, 상장일 3영업일 전)로 확정.
- 한화 제1우선주(비상장, 42,608주)는 신설에도 비상장 — 원장 대상 아님.

## 4. 영업일 간격 패턴 (2/2 일치 — 표본 적음, 추정에만 사용)
- 거래정지 공시 → 거래정지 시작: **+5영업일**
- 분할등기일 → 변경상장일: **+15영업일** (정지 시작 → 변경상장일 +17)
- 변경상장 공시 → 변경상장일: **+3영업일**(소각 4/4 관측과 동일)
- 신설법인 재상장 공시 → 상장일: 삼바 +2영업일(11/20→11/24), 한화 +2영업일(8/21→8/25)
