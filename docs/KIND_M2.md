## 1. 유상증자 (삼성바이오로직스 · 한화솔루션 · SK하이닉스 · SKC로 검증)
### 1.1 전문가 관점 → 규칙
| # | 관점 | 구현 |
|---|---|---|
| 1 | 결정 공시가 뜨면 증자 스레드를 연다 | `event(PAID_CAPITAL_INCREASE)`, 정정은 `정정대상 공시서류의 최초제출일`로 원 스레드에 붙음 |
| 2 | 왜 하는지 한 줄 | 자금용도 항목별 금액·비중, `타법인 증권취득자금`이면 같은 시기 `타법인 주식 및 출자증권 양수결정`에서 대상회사·지분 |
| 3 | 방식 확인(주주배정 주 트랙, 제3자배정 별도) | `track`: `RIGHTS`(주주배정·주주우선공모) / `THIRD_PARTY` / `PUBLIC`(일반공모) / `OTHER`(review_flag) |
| 4 | 지수는 **권리락일**에 증가(T+2 결제: 기준일 10/6 → 권리락 10/2) | 권리락일 = 신주배정기준일 직전 영업일(기준일이 휴장이면 직전 영업일의 직전 영업일). 권리락 공시가 나오면 그 값으로 확정. `index_share_adj` +신주수, 신주 상장 행이 원장에 생길 때까지 선반영 유지 |
| 5 | 핵심 날짜: 권리락 · 구주주 청약 종료 · 신주 상장 | 슬롯 17종, ★ 표시. 발행가는 예정 → 1차 확정 → 최종 확정 이력 |
| 6 | 제3자배정·공모는 신주 상장일 | `THIRD_PARTY`·`PUBLIC` 트랙 효력일 = 신주 상장일(추가상장 공시로 확정) |

### 1.2 슬롯과 출처
RESOLUTION(결정) · PRICE_FIRST_FIXED(`신주발행가액` 안내) · **EX_DATE**(`권리락 기준가격 안내`, 없으면 계산) · RECORD · RIGHTS_LIST_START/END·DELIST(`신주인수권증서 신규상장`, 없으면 투자설명서) · PRICE_FINAL_DUE · SUB_ESOP / SUB_OLD_START~END(★ 구주주 청약 종료) · PUBLIC_OFFER_START~END · PAYMENT · **NEW_SHARE_LISTING**(★, `추가상장(유상증자…)` 공시로 확정). 날짜의 90%는 결정 공시 하나에 들어 있다.

### 1.3 설계 판단과 발견
1. **신주인수권증서 거래기간**은 결정 공시에 없다 → 우선순위 ① `신주인수권증서 신규상장`(시장조치, 상장 임박 시 확정) > ② `투자설명서`(온디맨드: 증서 일정이 없을 때만 해당 법인 최신 1건 조회) > ③ 빈칸. 일관성 검사: 거래 5거래일 이상 + **폐지일 = 마지막 거래일의 다음 영업일**(실패 시 ⚠).
2. **정정이 잦다.** 한화솔루션은 정정 7회(7,200만주×33,300원 → 5,300만주×22,100원, 조달 2.40조 → 1.171조). 권리락 시점에 유효했던 수량을 기준으로 반영하고 발행결과(실발행)와 대조. SKC는 발행가가 예정가보다 **올라간** 사례(85,300 → 70,600 → 99,500원)로 가격 변경 방향 무관을 검증.
3. 권리락일 규칙은 삼바(10/6→10/2)·한화(6/16→6/15)·SKC(4/7→4/6) 모두 공시와 일치. `신주수 × 발행가 = 자금용도 합계` 정합성 검사도 3/3 일치.
4. 제3자배정 SK하이닉스 ADR은 국내 배정 대상 없이 해외 예탁기관에 전량 발행(결정 수량은 '최대 한도', 가격 결정 후 정정으로 확정). 효력일 = 신주 상장일(7/29).
5. 원장(`share_ledger`)은 신주 상장일에 늘고 지수(`index_share_adj`)는 권리락일에 이미 늘어 있다 — 삼바 10/8 기준 원장 46,290,951 vs 지수 48,560,951. 실권이 있으면 신주 상장일에 −실권(원장이 실제 상장 수량으로 교체).
6. 상장 공시(`추가상장(유상증자…)`)는 직전 스레드가 아니라 **계획 신주수가 가장 가까운 미매칭 스레드**에 붙는다. 권리락일이 시드 이전이면 `listed_as_of` 가 이후 첫 행의 증자 전 값을 쓰고, 원장 역방향 보완은 `m1_parser.fill_chain`.
7. SKC 삼중 검증: DART 반기 발행주식총수 49,598,298 − 신주 11,730,000 = 37,868,298 = 결정 공시의 증자 전 총수.
8. 한계: 우선주 배정·`주주우선공모`·일반공모 일부는 서식 미관측이라 `OTHER`/review. 자금용도는 규칙 기반 한 줄(시설자금 세부 투자처는 후속).

## 2. 자기주식 소각
**흐름**: `주식 소각 결정(+정정)` → [취득 후 소각이면 `자기주식 취득` 기간] → 소각일 → `변경상장(주식소각)` 공시 → **변경상장일 = 지수 감소일**(소각일은 무관).
- 기취득 소각 사례: 삼성전자(소각 4/2 → 변경상장 4/14, 4/13 5,919,637,922 → 4/14 5,846,278,608), SK하이닉스 1,530만주(2/9 → 2/23), 한화솔루션우 30,733주(8/4 → 8/18).
- **취득 후 소각**은 취득 시작일 단위 프로그램 스레드(`CXL:…:A<취득시작일>`)로 통합: 계획 결정 → 실제 종료일·수량 재결정 → 소각일 지정 결정이 같은 스레드에서 최신이 덮어쓴다. **변경상장 한 건이 소각일이 같은 여러 프로그램에 합산 적용**(KB금융·하나금융).
- 관측 규칙: 변경상장 공시일 + 3영업일 = 변경상장일(4/4), 소각일 → 변경상장일 7~9영업일.
- **변경상장 예정일**(공시 전 임시 추정): 소각일 + 중앙 약 11영업일 / 취득 종료일 + 과거 간격(법인별 관측 3건 이상이면 법인별 — 하나 92일·JB 24일·BNK 38일, 아니면 전체 중앙 36일). 취득 종료 후 45일이 지나도 매칭이 안 되고 추정일도 지났으면 `unmatched_stale`(완료 처리·리포트 제외). 추정 중앙값 +10영업일을 넘겼는데 공시가 없으면 비상장 종류주식 소각으로 보고 지수 영향 없음 처리(`no_listing_expected`).
- 취득 *실제 진행*(체결내역 누적금액·속도·예상 소진일)은 `buyback_exec.py`/`buyback.py`(HANDOFF 8절).

## 3. CB / BW
전환·행사 신주는 **신주 상장일**에 증가(M1 원장이 기록), M2는 회차(시리즈) 단위로 묶어 `발행 당시 가능 주식수 − 누적 전환 = 잔여 가능 주식수(희석 overhang)`를 추적. 전환가액 조정(리픽싱)은 추적하지 않음. 소량 규칙: 1천주 이하 이력 생략·10만주 이하 경미(CB/BW 에만).
- 검증: 하이브 CB 제4회(잔여 380,123주; DART 전환가능 447,474주와 일치), 엘앤에프 BW 제7회(잔여 1,643,318 = 5,964,185 − 4,320,867, 변경상장 공시와 일치), 엘앤에프 원장이 DART 자본금 변동(2025말 40,238,914 · 2026-06-30 40,683,260)과 일치.
- 발견: ① DART 발행주식총수는 *발행일*, 원장은 *상장일* 기준 → 시드 보정 `seed_adjust` ② 이사회가 같은 회차를 *신규 결정서*로 여러 번 재결의(BW 7회: 6/16·6/27·7/8·7/15) → (법인, 종류, 회차)가 같고 앞 납입일 이전이면 한 시리즈로 병합 ③ 발행일 서식 두 가지(`- 날짜 : N주` / `날짜(N주)`) ④ 상세검색 1년 초과 구간 0건 → 330일 분할 ⑤ 우선주 종류가 여럿(한화 1우 상장폐지, 3우B) → 종류 라벨별 코드 매핑.
- 잔여 전환·행사 현황(KIND 신고사항)은 '오늘'이 구간에 들어가 오프라인 재현이 안 된다 → 재생성 후 온라인 `m2_cbbw.py` 한 번.

## 4. 인적분할
- **존속**: 지수 감소일 = 변경상장일, 감소 수량 = 변경상장 공시의 `변경전 → 변경후`(종류별). **신설**: 별개 종목, 재상장일 = 존속 변경상장일, 결정 공시의 신설법인명을 KIND 에서 해석해 워치리스트 자동 추가(`m2_split.py --register`). **신설 상장주식수**는 재상장 공시 전 *계산값* = 존속 감소분 × (분할회사 1주 금액 ÷ 신설회사 1주 금액), 공시 수치가 나오면 덮어쓴다. **물적분할**은 범위 밖(스레드만, 주식수 조정 없음, 자회사 공시는 수집에서 걸러짐). 현금 처리(분할 후 첫 매매일 익일 기준시총 수정)는 주식수만 추적하므로 해당 없음 — 2026-11 개정 규칙은 근거 문서 수령 후(첫 사례 카카오).
- **흐름**: `회사분할 결정(+정정)` → `임시주주총회 결과` → `매매거래정지(회사분할에 따른 전자등록 변경, 말소)` → `변경상장(회사분할(존속))` → `변경상장 기준가격결정방법 안내`; 신설 쪽 `재상장(…)`. 결정 공시에서 읽는 것: 분할방법 #1 · 분할비율 #4 · 신설회사명·재상장 #7 · 감자비율·거래정지 예정·배정조건·신주 상장예정 #8 · 일정 #9. 공시 전에는 신주 상장예정일을 추정 변경상장일로, 감자비율×상장주식수를 예정 감소분으로 선반영.
- **사례**: 삼바(2025-05-22 결정, 정지 10-30, 변경상장 2025-11-24, 71,174,000 → 46,290,951) · 한화(2026-01-14 결정, 정지 07-30, 변경상장 2026-08-25, 보통 70,507,919 → 53,328,897 / 3우B 19,404,441 → 14,676,613). 한화 신설 보통주 계산 85,895,110 vs 공시 **84,515,535** — 분할 시점 자기주식에는 신주를 배정하지 않아 계산값은 상한 근사(우선주는 일치). 한화 제1우선주(비상장)는 원장 대상 아님.
- **영업일 간격(2/2, 추정에만)**: 거래정지 공시 → 정지 시작 +5, 분할등기일 → 변경상장일 +15, 변경상장 공시 → 변경상장일 +3, 신설 재상장 공시 → 상장일 +2.
- 한계: 신설 종류주식은 재상장 공시가 나와야 종목이 생김, 합병·물적분할·분할합병 미구현, 신설법인 M3 편입으로 designation 행이 늘어남(정상).

### 5.1 합병 소멸회사(상장사) 추적
`m2_corp_actions.py --register-extinct` 가 소멸회사명을 KIND 에서 해석(상장폐지 종목 포함, 표기 별칭 시도)해 `merger_extinct` 워치리스트에 등록 → 거래정지·상장폐지 공시를 수집해 `EXT_HALT_START`·`EXT_DELIST` 슬롯으로 연결. **관측(2/2): 소멸회사 상장폐지일 = 존속회사 신주 상장일**(HD건설기계 2026-01-26, 셀트리온 2024-01-12). 거래정지 시작은 신주 상장일 −16~18영업일 범위로만 추정. 비상장 소멸회사(SK E&S)는 건너뛰고, 소멸회사가 낸 같은 합병 결정은 존속회사 스레드 하나로만 본다. 소멸회사 별도 원장은 만들지 않는다.
- 진행 중: SK이노베이션 ← SK아이이테크놀로지(소규모, 신주 4,481,300주, 신주 상장 2027-01-18 예정; 금감원 정정명령으로 일정 변경 가능 — 리스크 태그), 대한항공 ← 아시아나항공(**소규모합병 확정** — 신주 20,337,721주 = 존속 발행주식의 5.52%, 신주 배정비율 1 : 0.2736432, 상장 2027-01-04 예정; 20% 이상 반대 통지 시 소규모합병 불가는 리스크로 기재). 이 서식에는 `합병비율` 항목이 없어 '주주가치에 미치는 영향' 문장에서 추출(`parse_decision` fallback).

## 6. 지수 3원칙 구현 위치
원칙 1(신규상장일)·2(주주배정은 권리락일)·3(소각은 변경상장일)과 분할·합병 규칙은 [`KIND_INDEX_METHOD.md`](KIND_INDEX_METHOD.md) · [`kind/index_rules.py`](../kind/index_rules.py) · `kind/index_shares.py`(`index_shares(sid, 기준일)` = 원장 + 선반영: 권리락일 ≤ 기준일이면서 해당 신주 상장 행이 아직 없는 증자). 신주 상장 *예정일*이 지났는데 공시가 아직 없어도 선반영은 상장 행이 생길 때까지 유지된다.
