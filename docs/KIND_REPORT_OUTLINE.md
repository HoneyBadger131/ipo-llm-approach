작성 2026-10-10 · 목적: 종목 확장(300종목) 전에 *보고서가 무엇을 보여줘야 하는가*를 실제 데이터로 점검한다. 아래 예시는 현재 DB(워치리스트 phase1 + k200_pilot + 분할 신설법인 + 합병 소멸회사)의 실제 값이다.

## 확정 사항 (2026-10-10 사용자 검토 반영)
- 구성: **다가오는 이벤트 목록 → 선택 시 상세**(DART 리포트 양식: 헤더 밴드·KPI 4·핵심 포인트·뉴스 근거·원문 링크 1개). 종결 건은 맨 뒤 7일 이내만(없으면 절 숨김).
- 정렬 = **|시총 변동|**(변동 주식수 × 기준일 종가). **상장주식수 기준**(유동비율 미적용). **우선주 제외**.
- 사람의 주의력은 한정 자원: 지수 주식수에 직접 닿는 것만 화면에, 나머지(우리사주·일반공모·정정 이력·근거 공시 나열·시장조치·종목별 원장)는 DB 에만. **중요 요소(변동 수량·시총 변동·반영일)는 ★ 표지.**
- 근거는 KIND 원문 링크 **하나**. '왜'는 한 줄 + 뉴스(`kind/news.json`, 기준일 이하 게재분만 — 사람이 검색해 추가).
- CB/BW 장기 대기는 한 줄(잔여 주식수·상장 대비 %·다음 주요일).
- 소멸회사 상장폐지는 별도 이벤트로 두지 않는다(합병 카드 안에서만).
- 종목 유니버스: **KOSPI 시총 상위 300**(벤치마크). `kind/universe/kospi_list_clean.md`(DART 모듈 290종목, 우선주 제외) + 시총 상위 300 종가(`kind/universe/prices_<날짜>.csv`, MCP `trading_data(scope=universe)` 한 번 호출). 이벤트 상대방(신설·소멸)은 자동 추가.
